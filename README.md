Launch-shape forecaster for GTA VI's release-day Twitch viewers: the hour-1 print anchors the scale, and the shape of hours 2–24 is learned at run time from the case's own comparables — a kernel-weighted local regression of each hour's log-ratio on the log hour-1 print (big launches grow less over the day), plus a rolling-midnight unlock bump for the US East/West coast joins. Python 3.13, standard library only, deterministic. Practice validation (4 past launches, local pinball scorer): mean loss 0.1497 vs house baseline 0.3871; 90% coverage 0.935.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
